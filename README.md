# Vega Pakistan + India Live TV Provider

This is a Vega provider that reads the public IPTV-org Pakistan and India country playlists and exposes their current stream URLs inside Vega.

## Install

1. Create a GitHub repository named `vega-providers`.
2. Upload `manifest.json` and the `dist/` folder from this package.
3. In Vega: Settings → Provider Manager → +.
4. Enter your GitHub username (if the repository is named `vega-providers`) or the full repository URL.
5. Confirm and enable **Pakistan + India Live TV**.

## Sources

Pakistan:
https://iptv-org.github.io/iptv/countries/pk.m3u

India:
https://iptv-org.github.io/iptv/countries/in.m3u

Streams are third-party/public playlist entries and can change or go offline. Availability and rights vary by channel and region.
